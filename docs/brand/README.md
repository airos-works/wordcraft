# ArtCraft brand marks

The ArtCraft name, wordmark and logos that upstream WordCraft keeps in this directory have been
removed from this fork, as [`LICENSE-brand.txt`](LICENSE-brand.txt) requires of a published
modified version: WordCraft for air/OS ships in air/OS images, so it must not carry the ArtCraft
Marks or present itself as an ArtCraft product. This repository credits upstream in plain text
only: WordCraft for air/OS is based on [WordCraft](https://github.com/storytold/wordcraft) by the
ArtCraft team. `LICENSE-brand.txt` is kept unchanged as the record of those terms.
